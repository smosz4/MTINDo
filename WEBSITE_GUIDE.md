## Design System

### Color Palette
- **Navy Blue (#0E2A54):** Primary color, headings, backgrounds
- **Deep Navy (#081b3a):** Footer, darker backgrounds
- **Red (#C4262E):** Accent, CTAs, highlights
- **Gold (#E3A92C):** Secondary accent, eyebrows, highlights
- **Paper Cream (#F6F3EC):** Background
- **Ink Black (#1A1A1A):** Body text
- **Soft Gray (#4A4A46):** Secondary text

### Typography
- **Headings:** Fraunces serif (font-weight: 700)
- **Body:** Archivo sans-serif (font-weight: 400-600)
- **Accents:** Space Mono monospace (uppercase, smaller sizes)

### Responsive Design
- Fully responsive for mobile, tablet, desktop
- Breakpoints at 860px and 480px
- Touch-friendly buttons and links
- Mobile-optimized navigation
