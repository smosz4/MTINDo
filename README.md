## How to Use

### To View the Website:
1. Navigate to your workspace folder: `c:\Users\GTM COMPUTERS\Desktop\MTINDO`
2. Open `index.html` in any web browser (Chrome, Firefox, Edge, Safari)
3. Navigate using the top menu: Home → About → Services → Programmes → Contact
4. Use the WhatsApp button (green button bottom-right) to contact MTINDO

### To Edit Content:
- **Update Programme Info:** Edit `programmes.html` and update the programme cards
- **Change Contact Details:** Search for the phone/email numbers and update all instances
- **Modify Services:** Edit service cards in `services.html`
- **Update About Info:** Modify text in `about.html`

### To Add Pages:
- Create a new `.html` file following the existing structure
- Include the navigation menu at the top
- Include the WhatsApp button at the bottom
- Link it from the main navigation in other pages
